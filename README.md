# 🎯 Job Acceptance Prediction System

## 📌 Overview

This project focuses on building a **Machine Learning-based Job Acceptance Prediction System** to predict whether a candidate will accept or reject a job offer.

The system analyzes candidate data such as academic performance, skills, experience, and interview outcomes to generate actionable insights for recruitment teams.

---

## 🚀 Objectives

* Predict job acceptance (Accepted / Rejected)
* Identify key factors influencing candidate decisions
* Handle real-world data issues (missing values, inconsistencies)
* Support data-driven recruitment strategies

---

## 💼 Business Use Cases

* Improve hiring efficiency
* Reduce offer dropouts
* Identify high-probability candidates
* Optimize recruitment and interview strategies
* Enable data-driven HR decisions

---

## 📊 Dataset

* 50,000 candidate records
* Includes:

  * Academic performance
  * Skills & certifications
  * Work experience
  * Interview scores
  * Job market conditions

---

## 🔍 Project Workflow

### 1. Data Cleaning & Preprocessing

* Handled missing values (mean/median/mode)
* Removed duplicates
* Treated inconsistent categorical values
* Applied encoding techniques
* Performed feature scaling

### 2. Exploratory Data Analysis (EDA)

* Analyzed patterns and relationships
* Correlation analysis
* Identified key influencing factors

### 3. Feature Engineering

* Experience category (Fresher/Junior/Senior)
* Skills match levels
* Interview performance categories

### 4. Machine Learning Modeling

* Problem Type: Classification
* Models Used:

  * Logistic Regression
  * Decision Tree
  * Random Forest

### 5. Model Evaluation

* Accuracy
* Precision
* Recall
* F1 Score
